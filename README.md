# Foodbe plugin for Claude

Foodbe gives Claude food facts from stored, human-approved data. It connects the Foodbe MCP server at https://mcp.foodbe.ai/v1/mcp and adds a skill that describes when to use it.

## Tools

- `foodbe_cart_breakdown`: analyze a food list or purchase
- `foodbe_ingredient`: ingredient profile
- `foodbe_compare`: compare two foods
- `foodbe_query` and `foodbe_query_all`: cited food answers
- `foodbe_recipe_finder`, `foodbe_meal_plan`, `foodbe_grocery_list`
- `foodbe_feedback`: send feedback to Foodbe
